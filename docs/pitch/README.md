# Sage pitch deck

Twelve-slide, editable HTML/CSS deck with PDF export and speaker notes. Kept outside the public website.

Serve this folder locally, then open index.html. Click Present for slide mode; arrow keys navigate and Escape exits. PDF is generated using Chrome print CSS.

Edit index.html for copy and deck.css for styling. The three Canva pointing frames are explicitly illustrations from the scripted website demo, not native-app recordings. Pricing, target customers, and sales targets are hypotheses.
